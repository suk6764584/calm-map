# 무던한 지도 (Calm Map)

감각과민이 있는 아이와 외출할 때, 평균 소음이 아니라 **갑자기 튀는 큰 소리(깜짝 소리)** 가 적은 시간과 장소를 고르게 돕는 시제품입니다.
2026 AI 라이프 솔루션 챌린지 출품작(아이디어 챌린지 수상 후보작 「무던한 지도」 구현).

**시제품:** https://suk6764584.github.io/calm-map/ (로그인 없이 열림, 파일 하나로 동작)

## 무엇을 예측하나
- 자료: 서울 S-DoT 환경정보 소음 센서 1,025곳, 2026-08-17~10-11 8주 실측(1시간 단위 최대·평균 소음, 102만 센서·시간)
- 깜짝 소리: 한 시간 안 최대 소음이 평균보다 10dB 이상 높은 때(전체의 2.7%)
- 모델: 그래디언트 부스팅 분류(HistGradientBoosting), 특징 15개, 3~7주차 학습 · 8주차(10/5~10/11) 시험

| 시험 주 지표 | 모델 | 지난주 그대로 | 같은 시각 평균 |
|---|---|---|---|
| 깜짝 소리 AUC | 0.856 | 0.735 | 0.685 |
| 추천 낮 2시간에 실제 깜짝 소리 | 3.3% | 3.9% | (무작위 4.5%) |

계속되는 소음은 지난주 실측이 모델보다 오차가 작아(1.13dB 대 1.26dB) 화면에 실측을 그대로 보여 줍니다.

## 한계
센서가 길가 가로등·건물 벽에 달려 있어 공원 깊은 안쪽보다 입구·길가의 소리에 가깝습니다.

## 파일
- `index.html` — 시제품(스타일·자료·코드를 한 파일에)
- `src/prep.py` · `src/model.py` · `src/export.py` — 자료 정리, 학습·검증, 화면용 자료 만들기 · `src/eval.json` 검증 결과
- `src/app/` — 시제품 원본(나뉜 파일)

자료 출처: 서울특별시 S-DoT 환경정보(서울 열린데이터광장).
